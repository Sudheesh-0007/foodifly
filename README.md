# Foodifly - Digital E-commerce Platform

Foodifly is a premium, full-stack Django e-commerce web application designed for gourmet food enthusiasts. It features a custom user authentication system, dynamic cart management, and a luxurious UI.

## Features
* **Custom User Authentication:** Uses email-based login with a custom `Account` model and OTP verification.
* **Dynamic Cart & Checkout:** Real-time cart updates, secure checkout, and order management.
* **User Dashboard:** A comprehensive account overview including order history, wishlist, and dynamic address management.
* **Product Catalog:** Category-based filtering, detailed product views, and inventory tracking.
* **Admin Panel:** Customized Django admin interface for easy store management.

## 🚀 Tech Stack
* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **Database:** PostgreSQL (or SQLite for local dev)
* **Styling:** Custom CSS with luxury typography (Playfair Display, Inter)
